# Asset sources

- `assets/lianna-demo.mp3`: Lianna's `1st.mp3` from her original portfolio repository. Display title: Demo 01.
- `assets/portrait.jpeg`: the illustrated avatar in her original portfolio (`webpic.jpeg`); it is not presented as a real photograph.
- `assets/favicon.png`: original portfolio favicon.
- `assets/qre-equity.png`, `market-making.png`, and `isrg-model.png`: outputs from the reviewed project packages in this workspace.
- DM Sans and Space Grotesk: Google Fonts; SIL Open Font License. Font license texts are included with the font assets.
- Hand tracking: MediaPipe Tasks Vision 0.10.21, loaded only after opt-in from jsDelivr, with the Google-hosted Hand Landmarker model and WASM files. These optional remote dependencies are not embedded in the standalone HTML.
- Financial symbols, chart motion, fabricated order examples, and interface illustrations are decorative or explicitly labeled examples, not live financial data.

Original portfolio: https://github.com/lrb2006/lrb2006.github.io
MediaPipe documentation: https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker?tab=Web
